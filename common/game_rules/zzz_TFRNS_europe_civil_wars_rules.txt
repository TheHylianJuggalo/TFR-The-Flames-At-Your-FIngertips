# TFR No Surrender - European civil war winner rules
#
# Four "winner" rules for the civil wars that only break out on the Soviet
# victory paths. TFR itself decides these wars by normal combat and
# capitulation; these rules do not invent any new logic - they simply give the
# chosen side the same Mushroom Army attack buff the other submod winner rules
# hand out, for as long as the war is actually being fought. DEFAULT leaves TFR
# exactly as it is.
