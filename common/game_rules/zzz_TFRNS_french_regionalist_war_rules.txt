#

# If a breakaway kills Lambart's France, TFR hands France to Germany and Germany
# declares civil war on all eight. This rule does not change that script; it only
# hands the Mushroom Army attack buff to either France or every regionalist while
# that first phase is being fought. The buff is stripped from all eight the moment
# France capitulates, so the Germany-versus-everyone phase starts clean.
# DEFAULT leaves TFR untouched.
